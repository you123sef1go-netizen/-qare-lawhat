خطوات النشر من الموبايل:
1. فك ضغط ZIP.
2. أنشئ مستودع GitHub خاصاً (Private) وارفع كل الملفات والمجلد public كما هي.
3. في Render اختر New > Web Service واربط مستودع GitHub.
4. الإعدادات: Runtime Node، Build Command: npm install، Start Command: npm start، واختر Free إن كان متاحاً.
5. بعد الإنشاء افتح Environment وأضف متغيراً:
   Key: ASSEMBLYAI_API_KEY
   Value: مفتاحك السري (ألصقه في Render فقط)
   ثم Save, rebuild, and deploy.
6. افتح رابط onrender.com وجرب ملفاً قصيراً أولاً.

الأمان: لا تضع المفتاح في GitHub أو ملفات المشروع أو الواجهة. اجعل المستودع Private.
التسجيل يُرسل إلى AssemblyAI. Universal-2 يدعم العربية، لكن دقة أسماء حروف اللوحات باللهجة المصرية يجب اختبارها.
حد الملف في التطبيق 250MB مبدئياً؛ قد توجد حدود أخرى لدى مزود الاستضافة. الخطة المجانية قد تنام ولها موارد محدودة؛ لا يوجد ضمان لسرعة ساعة كاملة أو أن كل الاستخدام مجاني. تحقق من الرصيد وحدود حساب AssemblyAI.
هذا نموذج أولي غير مهيأ للإنتاج أو لتخزين المهام بشكل دائم.
